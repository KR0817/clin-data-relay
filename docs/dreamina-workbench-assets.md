# Dreamina Workbench Visual Assets

**Date:** 2026-08-22  
**Scope:** decorative workbench assets only

Two source images were generated with the official Dreamina CLI using model
5.0 at 2k resolution and one output per prompt. Total provider cost was six
credits. A third independent empty-state submission was attempted but stopped
after repeated provider user-info timeouts; no task was created and no credit
was charged. The review empty state is therefore a compositional crop of the
approved central source, not a separate model claim.

The provider placed an `AI-generated` mark in the top-left source margin. The
shipping derivatives use fixed geometric crops that exclude that margin. No
inpainting or semantic alteration was used. Source files, prompt files,
credential-free task metadata and the SHA-256 ledger stay under
`packaging/assets/`; only the three compressed WebP derivatives are served by
the application.

Human review confirmed that the shipping derivatives contain no people,
patient likeness, direct identifiers, readable report content, clinical image,
hospital mark or action/status text. They are decorative and must keep an empty
accessible name. The ledger is the file-level provenance source of truth.
