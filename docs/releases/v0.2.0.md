# ClinData Relay v0.2.0 source-only marker

Tag `v0.2.0` records the initial `AGPL-3.0-only` source baseline. A clean
Windows Lite build from this tag exposed an undeclared local
`vendor/tessdata_fast` prerequisite, so no GitHub Release or binary assets are
published for this version.

Version `v0.2.1` adds an immutable-upstream, SHA-256-verified preparation step
and is the first downloadable release. The clinical and production safety
boundaries described in the repository remain unchanged.
