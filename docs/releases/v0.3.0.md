# ClinData Relay v0.3.0

Version `v0.3.0` adds executable evaluation infrastructure and a controlled
OpenAI-compatible model-provider boundary while preserving the human-review and
Authority EDC design.

## Highlights

- A versioned synthetic benchmark command scores strict and normalized field
  extraction, report-level exact matches, report-clustered confidence intervals
  and paired arm differences under a frozen error taxonomy.
- Kimi remains the default provider, while an operator can configure another
  explicitly allow-listed OpenAI-compatible endpoint without changing the
  review workflow or exposing transport settings through the browser.
- The Windows Lite release is black-box tested with an obviously synthetic
  image and pulmonary-function PDF. Verification covers missing-key local
  fallback, 19 reviewed candidates in total and reviewed Excel export.
- No live model request, real participant material or clinical-performance
  claim is part of the release build or benchmark demonstration fixtures.

## Windows Lite assets

- `ClinicalReportExtractorLite-windows-x64.zip`
- `ClinicalReportExtractorLite-windows-x64.sha256`
- `ClinicalReportExtractorLite-windows-x64.verification.json`

The archive is unsigned. Verify the standalone SHA-256 value before extraction.
The machine-readable report records the packaged synthetic checks performed by
the release builder.

## Safety boundary

This remains a research prototype. OCR and model outputs are candidate values
requiring authenticated human review. LibreClinica remains the Authority EDC
when its optional adapter is used. Public source, automated tests and a GitHub
Release do not establish clinical validation, institutional approval or
production readiness.

## Known limitations

- Central PostgreSQL and institution-managed identity remain fail-closed and
  are not composed into the production HTTP runtime.
- The Windows binary is not code-signed.
- The benchmark package includes only metric-engine demonstration fixtures; it
  does not report extractor accuracy or model benefit.
- Clinical validation, threat-model review, backup/restore drills and
  institution-owned operations remain required before real use.
- `CITATION.cff` has no DOI until the owner completes an external archival
  deposit.
