# 中心数据包运行手册

本手册对应“中心本地工作台 → 加密中心包 → 中央批量导入”的离线交换模式。中心工作台不需要访问医院的 LibreClinica；中央汇总库只接受中央数据管理员导入，导入后仍由中央管理员或牵头研究者查看。

## 1. 中心首次准备

1. 为每个中心创建独立的 `site_investigator` 账号和唯一中心代码，例如 `SITE_A`、`SITE_B`。不要在多个中心复用账号或代码。
2. 在 Windows 中打开“设置 → 隐私和安全 → 设备加密/BitLocker”，完成系统盘加密并保存恢复密钥。命令行核验可使用管理员 PowerShell：

   ```powershell
   manage-bde.exe -status C:
   ```

   必须看到“已加密百分比: 100.0%”且“保护状态: 保护已启用”（中文系统即使显示“仅加密了已用空间”，100% 也视为完成）。恢复密钥不能和数据包放在同一目录。
   如果命令提示拒绝访问，请以“管理员身份”打开 PowerShell；工作台本身不会申请或保存管理员凭据。也可以运行只读核验脚本：

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\verify_disk_encryption.ps1
   ```

3. 在 macOS 中打开“系统设置 → 隐私与安全性 → FileVault”，开启 FileVault，保存恢复密钥。核验可使用：

   ```bash
   fdesetup status
   ```

4. 登录工作台后，`/api/health` 和“磁盘安全状态”接口会报告当前平台的 BitLocker/FileVault 状态。状态为 `disabled` 或 `unknown` 时，不应在该设备上保存原始检查单。

## 2. 识别与审核

1. 填写去标识化病人研究编号，选择访视，上传一张或多张图片/PDF。
2. 按批准流程核对遮盖预览；确认后才运行本地 OCR。Kimi（如已启用）只接收去标识化衍生图和 OCR 证据，不能接收原图。
3. 逐项审核候选值。只有中心研究者或中央数据管理员能接受、修改、拒绝；其他角色不能改变候选状态。

## 3. 生成加密中心包

1. 在“数据包密码”输入至少 12 位密码，点击“生成加密中心包”。
2. 生成文件使用 AES-256-GCM 加密，密码通过 scrypt 派生密钥；文件内只含人工确认的去标识化值、字段字典版本和来源 SHA-256。
3. 包内不包含原图、图片路径、OCR 文本证据、姓名、电话、住院号、身份证号或审核人邮箱。密码通过独立渠道交给中央数据管理员，不写入文件名、备注或日志。

## 4. 中央批量导入

1. 中央数据管理员登录中央账号，在同一页面选择多个加密中心包，输入对应密码后批量导入。
2. 系统逐包执行：外层 SHA-256 校验、AES-GCM 认证解密、中心代码校验、活动字段字典 ID/版本校验、防重复导入和字段白名单校验。
3. 页面会显示成功、重复和失败数量；中央运营区的“中心包导入日志”保留文件名、包 SHA-256、中心代码、字典版本、导入结果和失败明细。重复包不会创建候选值。
4. 导入结果只进入伴随数据库的人工确认记录，不自动连接或修改 LibreClinica。若需要向权威 EDC 提交，必须由有权限的研究者在工作台中主动冻结并提交。

## 5. 备份与原图清理

- 启动脚本会对已有本地 SQLite 数据库执行在线备份，并在临时库中运行 `PRAGMA integrity_check`。证据文件、备份 SHA-256 和恢复检查结果写入 `.runtime/backups`。
- 可用 `COMPANION_ORIGINAL_RETENTION_DAYS` 配置原图保存天数（默认 30 天，范围 1–3650）。到期清理必须由维护人员显式执行：

  ```powershell
  .\.venv\Scripts\python.exe scripts\cleanup_expired_originals.py --execute
  ```

  清理会删除物理原图、保留哈希和审计记录，并将后续读取返回为“内容已到期清理”。默认不自动删除，避免误删未完成审核的资料。

- 备份目录应放在已加密磁盘或机构批准的加密存储中，并定期在隔离位置做恢复演练。备份密码/密钥不得与备份文件同处。

## 6. 交付前检查

- 每个中心只有自己的账号和中心代码；中央汇总账号只授予牵头研究者或中央数据管理员。
- 设备磁盘加密状态为 `enabled`。
- 最近一次备份存在有效 SHA-256 和恢复检查证据。
- 中心包导入日志中无未处理失败；字典版本一致。
- 导出包抽检确认不含原图和直接身份信息。
