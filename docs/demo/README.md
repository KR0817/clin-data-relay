# Two-minute demo

`clin-data-relay-demo.mp4` is a silent, two-minute, 1280x720 product tour built
entirely from synthetic data. It shows the centre workflow, human review,
encrypted exchange, duplicate and dictionary-version gates, and the Authority
EDC boundary.

The reproducible Remotion source and render commands are in
[`showcase/demo-video`](../../showcase/demo-video/README.md).
