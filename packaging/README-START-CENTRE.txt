中心专用检查报告录入工具（Windows x64）
========================================

首次使用
--------
1. 将整个 ZIP 解压到本机可写文件夹，不要直接在压缩包中运行。
2. 双击带蓝色盾牌/检查单图标的 Start-Clinical-EDC-Lite.exe。若本机策略要求命令入口，再运行 compatibility\Start-Clinical-EDC-Lite.cmd。
3. 浏览器会显示本安装包固定的中心代码和研究者账号。
4. 点击“生成随机密码”，再点击“保存并显示一次性凭证”。
5. 在一次性凭证页复制或下载账号密码，保存到获批的密码管理器，然后进入工作台。

安装包不含初始密码、中央管理员账号、其他中心账号、历史数据库、上传文件或 Kimi 密钥。
密码明文不会写入数据库、日志或本地配置文件。若密码遗失，关闭工作台后双击
Reset-Centre-Password.cmd；新密码只在本机命令窗口显示一次，并会注销旧会话。

日常流程
--------
填写去标识化研究编号和访视，上传 PDF/图片，选择识别项目，核对去标识化预览，运行识别，人工审核，再导出 Excel 或生成加密中心包。

Kimi
----
Kimi 默认启用。登录网页后点击“配置密钥”，输入本中心自己的 API 密钥并保存即可立即使用；Configure-Kimi.cmd 仅作为备用方式。未配置密钥时，本地 PDF 解析和本地 OCR 仍可使用。禁止将含直接身份信息的原图发送给 Kimi。

安全边界
--------
- 程序只监听本机 127.0.0.1，不是共享服务器。
- 中心包只包含人工确认的去标识化字段值、字典版本和来源 SHA-256，不包含原图。
- 数据包密码必须通过独立渠道交给中央数据管理员。
- 本机应启用 BitLocker，并按批准期限清理原图。
- 本工具不连接 LibreClinica；中央汇总与权威 EDC 操作由牵头中心完成。

完整性
------
MANIFEST.sha256 记录包内文件哈希。当前构建未进行商业代码签名，机构分发前仍需完成恶意软件扫描、签名和批准的软件验证记录。
